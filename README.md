# Unblock

**Unblock** is a learning assistant designed to help students move forward when they’re stuck — without giving direct answers.

Instead of solving problems for you, Unblock guides your thinking through hints and questions, while keeping track of the topics you struggle with over time.

---

## What It Does (So Far)

- Lets students submit a problem or describe where they’re stuck  
- Uses AI to respond with **guiding questions and hints**, not solutions  
- Identifies the subject and skill involved in each request  
- Tracks repeated “stuck moments” to highlight weak areas  
- Displays a simple progress view of topics you’re working on  

---

## Why Unblock?

Most study tools prioritize answers.  
Unblock prioritizes **understanding**.

The goal is to support real learning by encouraging students to think through problems, similar to how a good tutor guides rather than tells.

---

## Tech Stack (Early Stage)

- **Frontend:** React / Next.js  
- **Backend:** Flask or API routes  
- **AI:** Large Language Model (LLM) with strict prompt constraints  
- **Storage:** Lightweight database (Firebase, Supabase, or SQLite)

---

## Project Status

This project is in **early development** and was started as part of a hackathon.  
Features, structure, and scope are still evolving.
